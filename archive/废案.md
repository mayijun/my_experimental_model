## 废案 1：两阶段 Flow Matching + JEPA 字符级文本生成器

- **归档日期**：2026-11-24
- **状态**：实现代码已删除（`flow_matching_jepa.py`、`pretrain.py`、`eval_generate.py`、`analyze.py`、三个 `run_*.sh` 启动脚本）
- **保留**：[math.md](math.md) 继续作为理论文档；本文档记录实现思路与实测结论
- **代码规模**：约 35 KB 单文件教学版 + 3 个外围脚本；0.3B 配置（dim=1024, heads=16, enc=4, flow=12, seq=256, vocab=6050）

### 1. 核心思路

用「联合嵌入预测（JEPA）+ 条件 Flow Matching」在**连续潜空间**里生成离散文本，两阶段串行：

1. **阶段一（表征）**：双编码器（在线 $E_\theta$ + EMA 目标 $E_\xi$）在随机掩码预测下学连续潜表征，再经离散量化瓶颈（FSQ / VQ / RVQ），由解码器还原字符。
2. **阶段二（生成）**：冻结编码器，用线性（OT）插值路径训练条件速度场 $v_\psi(z_t,t,c)$；推理时 Euler/Heun 积分把噪声流成潜变量，量化后并行解码。

要回答的三个命题（详见 math.md §2、§4、§6）：

- 文本是连续潜空间的有损压缩：$H(T) \le L\log_2|\mathcal{V}|$ 与 $D_T = \mathbb{E}\|Z - E_\theta(T)\|^2 > 0$ 同时成立。
- 文本不是随机丢弃，而是在固定码率下最大化 $I(T;Y)$ 的确定性信息瓶颈：**语义在、措辞丢**。
- 并行解码的串行深度 $O(N)$ 与序列长度解耦，优于自回归 $O(L)$。

### 2. 数学要点

**JEPA 阶段**

$$
\mathcal{L}_{\text{jepa}} = 1 - \cos\!\big(P_\phi(E_\theta(x_c)),\ \mathrm{sg}[E_\xi(x)]\big),
\qquad \xi \leftarrow \mu\xi + (1-\mu)\theta
$$

总损失（阶段一）：

$$
\mathcal{L} = \mathcal{L}_{\text{jepa}} + \mathcal{L}_{\text{rec}} + 0.5\,\mathcal{L}_{\text{masked-rec}} + 0.1\,\mathcal{L}_{\text{var}} + \mathcal{L}_{\text{quant}}
$$

- $\mathcal{L}_{\text{rec}} = \mathrm{CE}(g(\mathrm{Q}(E_\theta(x))), x)$：量化潜变量必须能还原文本；
- $\mathcal{L}_{\text{masked-rec}} = \mathrm{CE}(g(\mathrm{Q}(P_\phi(c))), x)$：解码器也要能读「预测出来的」潜变量；
- $\mathcal{L}_{\text{var}} = \mathrm{relu}(1-\mathrm{std}(z))$ 的均值：VICReg 式方差正则，抑制维度塌缩；
- EMA 系数 $\mu = 0.99$，目标编码器只随优化器步进更新。

**量化瓶颈（FSQ）**：逐维取整 + 直通估计

$$
z_q = \frac{\mathrm{round}\!\left(\frac{K-1}{2}\tanh z\right)}{(K-1)/2},\qquad K=5
$$

前向取整、反向视为恒等；$K=5$ 时每维落到 $\{-1,-\tfrac12,0,\tfrac12,1\}$。

**Flow 阶段**：线性概率路径与条件速度场

$$
z_t = (1-t)z_0 + t z_1,\quad z_0\sim\mathcal{N}(0,I),\ z_1 = \mathrm{sg}[E_\xi(x)]
$$
$$
\mathcal{L}_{\text{FM}} = \mathbb{E}_{t,z_0,z_1,c}\big\|v_\psi(z_t,t,c) - (z_1 - z_0)\big\|^2
$$

推理即解 ODE $\;\mathrm{d}z/\mathrm{d}t = v_\psi(z,t,c)\;$：

- Euler：$z \leftarrow z + \Delta t\,v(z,t)$
- Heun（二阶预测-校正）：$k_1=v(z,t),\ k_2=v(z+\Delta t k_1, t+\Delta t),\ z \leftarrow z + \tfrac{\Delta t}{2}(k_1+k_2)$

因为条件 $c$ 在积分各步不变，交叉注意力的 K/V 只算一次（KV 缓存），每步只重算随 $z$ 变化的 query 与自注意力。

### 3. 实现结构（供重建参考）

| 组件 | 职责 |
|---|---|
| `ContextEncoder` | Token Embedding + 学习位置编码 + Pre-LN TransformerEncoder，输出 `[B,L,d]` |
| `update_target` | EMA 同步目标编码器 $\xi \leftarrow \mu\xi + (1-\mu)\theta$ |
| `make_corrupted_context` | 每样本随机掩码比例 `[min_ratio, max_ratio]`，只替换上下文、干净目标不变 |
| `variance_loss` | VICReg 式方差正则 |
| `reconstruction_loss` | 量化潜变量 → 解码器的交叉熵 |
| `IdentityQuantizer / FSQ / VectorQuantizer / ResidualVQ` | 四种前向压缩 $p(T\mid Z)$；VQ 用 EMA 码本、RVQ 逐级量化残差 |
| `FlowBlock` + `FlowPredictor` | 自注意力 + 交叉注意力（读上下文 $c$）+ 时间正弦嵌入，输出速度场；带 KV 缓存快路径 |
| `Decoder` | 后期改为「位置混合 Transformer + 逐位置线性头」；最初是**逐位置 `nn.Linear`，无位置混合** |
| `flow_sample` | Euler / Heun 积分，batch 维并行 |
| `decode_latents` | 量化 → 解码 → argmax 或按温度采样，屏蔽 `[MASK]` |
| `maskgit_decode` | 迭代预测 + 按置信度提交，逐步细化 |
| `posterior_demo` | 同一文本采多条潜变量轨迹，度量 $p(Z\mid T)$ 的模糊性 |
| `SemanticFlow` | 预留的低维语义因子流（$d_y$ 维），**未接入训练** |

训练配置：阶段一 AdamW lr $2\times10^{-3}$；阶段二冻结编码器与量化码本，AdamW lr $10^{-3}$ 只训 Flow 与解码器。全量 15.9 亿字符、每阶段 388,444 步（batch 16）。

### 4. 实测结果

**A. 一阶段模型（dim=1024，1 epoch / 约 1 亿字符）**

| 指标 | 数值 |
|---|---|
| 重建 ppl / top-1 / top-5 | 2.56 / 84.6% / — |
| 真实潜变量直接解码 top-1 | 95.5% |
| 重编码自洽率 | 99.41% |
| 条件 flow 生成 top-1 | 5.8% |
| 预测器生成 top-1（仅统计掩码位） | 16.2%–19.7%，但**只输出 1–4 种字符**（退化为空格） |
| 语义流（$d_y=64$）生成 top-1 | 1.4%–3.5%（字符 trigram 12.2 bits/char ≈ 均匀 12.56，即噪声） |

| 原条件 flow | 6.0% | 0.05 | 7.2–8.2 | 局部成型、不成句 |
| JEPA 预测器（零训练） | 16.2% | 0.19 | 2.32 | 常量空格 |

### 5. 废弃原因

1. **条件信息不足**：编码器在掩码位置上的表示 $c$ 几乎不携带逐位置信息。证据：20 步采样得到的潜变量若去掉「跨位置公共分量」后与真值的余弦只剩 0.04；预测器的输出也坍缩为位置无关的常量。
2. **解码器对潜变量误差零容忍**：教师路径 $y$ 余弦 0.997 → top-1 99.6%；采样路径 $y$ 余弦 0.77 → top-1 3.8%。逐位置 `nn.Linear` 解码把任何潜变量误差直接放大成乱码。
3. **流模型退化为均值回归**：$p(z\mid \text{mask})$ 近似退化时，Flow 的 MSE 目标只会学到条件均值，采样出的「细节」与真值无关。
4. **低维语义流无法突破**：$d_y=64$ 的语义瓶颈只保留「公共语义」，逐位置细节全丢；把预测器作为条件加入（组合方案）也没有增益。
5. **`sampled_recon` 设计有误**：用 $t\sim U(0,1)$ 的单步 Euler 端点估计训练解码器，$t\to0$ 时端点就是纯噪声，解码器被迫「无视输入硬猜」，ppl 从 2.56 崩到 16226（比均匀分布 6050 还差），自洽率跌到 31%。

### 6. 若要重启，这些是已知的坑

- `sampled_recon` 必须按 $t>0.5$ 门控并降权（如 0.3）；更彻底的做法是用真实 3–5 步小采样生成训练用的潜变量，而不是单步端点近似。
- 位置混合解码器本身有效（生成文本出现真实短语），但它需要「先冻结主模型训练解码器、再小学习率解冻」的两段式，否则会把表征带崩。
- 评价生成质量不能只看 top-1：必须**只统计掩码位**，同时报「唯一字符数 / 字符熵」，否则「全输出空格」会被误读成 16% 准确率。
- 更根本的瓶颈是条件编码器的逐位置可预测性（掩码策略、训练步数、上下文窗口），而不是采样器；在编码器未达标前，换任何生成器都不解决问题。

### 7. 仍然可复用的部分

- `FlowBlock` 的交叉注意力 KV 缓存实现（上下文不变时每步只算 query）；
- FSQ 的直通估计写法与 VQ/RVQ 的 EMA 码本更新；
- `variance_loss`（VICReg 式防塌缩）；
- 评测口径：重建 ppl / 掩码位 top-1 / 字符 trigram bits / distinct-n / 相邻重复率 / 多次采样一致率；
- math.md §2.2（JEPA）、§4.1（Flow Matching）、§4.3（离散瓶颈与并行）、§6（可检验推论）的推导本身与实现无关，仍然有效。
